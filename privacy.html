Privacy Policy

Effective date: November 17, 2026

Fabrica Videos ("the tool") is a private, internal tool that uploads and schedules videos on the YouTube channels operated by its owner. It has no users other than its owner.

YouTube API Services

The tool uses the YouTube API Services. Use of the tool is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses

With the owner's authorization, the tool requests only two permissions:

  • Upload videos (youtube.upload): to upload the owner's videos, set their details and scheduled publish time, and set their thumbnails.
  • Read-only access (youtube.readonly): to read the name and ID of the authorized channel and confirm that each video is uploaded to the right channel.

The tool does not access, collect or store information about any other YouTube user or channel.

How information is stored

  • The authorization tokens are stored only on the owner's own computer and are never sent anywhere other than Google.
  • The tool keeps only the IDs of the owner's own channels and of the videos it has uploaded, to manage those uploads.
  • The tool does not use cookies, analytics or any other tracking.

Sharing

No information obtained through the YouTube API Services is sold, shared with or transferred to any third party.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account third-party connections page (also available at security.google.com/settings/security/permissions). When access is revoked, the stored tokens stop working and are deleted from the owner's computer.

Changes

Any change to this policy will be published on this page with a new effective date.
